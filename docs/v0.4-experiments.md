# V0.4 — calibration and phase-load root-cause study

Node.js 18+, no dependencies: `node test-v4.mjs`; `node test-v4.mjs --diagnostic`; add `--full` for per-group results.

## Method
Keep KernelV3 unchanged. Add causal observer, conditional residual service estimates, estimated blocked-job wake times, recent arrival rate projection, alternative objective, evaluation cadence/dwell, and explicit candidate traces. Forecast approximates jobs by one remaining CPU burst, ignores subsequent bursts, treats synthetic arrivals as estimates, and omits computation cost. Completed CPU bursts and past transitions only; one equal-visible-history fixture passed, not a proof of masking. Controller state is separate from kernel snapshot; closed-loop replay not yet supported.

Training: 60 groups, seeds 201–204, 660 runs, seven predefined candidate configurations (all start MLFQ), four baselines. Minimize mean RR-normalized equal-weight response/turnaround score, denominator floor 1. Selected 'aligned': horizon/interval 48, margin 8%, response weight 4, turnaround term enabled, no survival/wake/arrival modules, no extra dwell. Weights and parameter grid are engineering choices, not user SLAs. Objective alignment is approximate; forecast charges queue waiting, fresh-job additional waiting and optionally productive CPU ticks, not a full future turnaround model.

Test: 144 groups, seeds 301–308, six workload families including reverse phase, 1296 runs (three disabled-feature removal variants are identical to selected config; not independent evidence). Results: RR 1.0000; MLFQ 0.8497; V3 1.1534; V4 0.8824; V4 reference starting MLFQ 1.0819. V4 strictly beats per-group best static in 75/144, V3 in 27/144. V4 mean response 32.06 ticks, turnaround 453.71; MLFQ 23.14 and 571.37. V4−MLFQ mean paired score difference +0.03277; illustrative 95% percentile cluster bootstrap interval [+0.00347,+0.05827], 4000 resamples, only 8 seed clusters; not a general population significance guarantee. Phase score V3 1.4816, V4 1.0819, MLFQ 0.8461; reverse 1.2657, 0.9181, 0.8408. All runs completed with existing kernel invariants. V4 is not a proven better default.

## Follow-up single-factor diagnostics
36 new groups (phase/reverse, seeds 401–406, costs 0/1/3), 432 runs. Conducted after test, exploratory; no retuning of frozen V4. Mean scores: static MLFQ 0.8273; reference 1.3476; response weight only 1.0147; turnaround term only 1.3144; both 1.0137; both starting RR 1.0690; add survival 1.0088; add wake 1.1691; add arrival 1.0320; short interval 1.0181; add dwell 1.0137. Response-weight underemphasis is a reproducible contributor within these synthetic conditions; no universal root-cause claim. Extra wake prediction worsened mean; more complexity is not automatically useful. The diagnostic uses a different set of seeds and must not be used as a new unbiased confirmatory set if tuning against it.
